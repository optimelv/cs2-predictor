# Home map artwork sources

The three hero images are oil-painted edits of real Counter-Strike 2 screenshots. The scene geometry and camera framing were retained during image generation. They are decorative art, not match evidence or official Valve artwork.

| Map | Screenshot used as edit base | Site asset |
| --- | --- | --- |
| Dust II A site | [GhostCap source](https://github.com/ghostcap-gaming/cs2-map-images/blob/main/cs2/de_dust2.png) | `dust2-oil.webp` |
| Inferno B site | [GhostCap source](https://github.com/ghostcap-gaming/cs2-map-images/blob/main/cs2/de_inferno.png) | `inferno-oil.webp` |
| Ancient | [GhostCap source](https://github.com/ghostcap-gaming/cs2-map-images/blob/main/cs2/de_ancient.png) | `ancient-oil.webp` |

The [source repository](https://github.com/ghostcap-gaming/cs2-map-images) expressly offers these screenshots for CS2-related projects. Valve's [Steam Subscriber Agreement, section 2.D](https://store.steampowered.com/subscriber_agreement/) permits game-content fan art on a non-commercial basis; review rights before adding ads, subscriptions, or other commercial use. The edited WebP assets are 1440 px wide and load only when selected as the current visit's static background.
