# StrikeSignal interface system

Direction: Taste true-black-flat, seed 753842474. Compact Nova geometry,
Sora, neutral surfaces, orange on prediction data rather than navigation chrome.

## Product jobs

- Matches: find a series, see its actual status, inspect its prediction and evidence.
- Events: find a supported main event and follow a real result through its stages.
- Players: locate a player and distinguish dated statistics from missing fields.
- Picks: save a deliberate choice only while the underlying match data is eligible.

The signature is the match pair: two named teams, one probability comparison,
separate source result and model estimate. No generic KPI dashboard.

## Foundations

One neutral ramp per appearance, one orange data accent, dedicated warning and
error tokens. Sora from the existing local font files, 12/14/16/24/32px roles.
Tabular figures for scores and probabilities. Four-pixel spacing unit; 16px
component gap, 32px section gap, 1200px maximum canvas, 20px phone gutters.
Default controls 36px, touch controls at least 44px. Radius 4px chips, 6px
controls, 8px panels. No resting shadows; overlays may float.

## Components

Official shadcn Base UI components, Nova style. Lucide is the configured icon
library for this foundation; existing Rune icons remain in the legacy views
until migrated. Components own variants; views own layout. Never put a raw
brand color or a custom control implementation in a view.

Button, Tabs, Input/Field, Dialog, Avatar, Alert, Empty, Badge, Skeleton,
Tooltip and Select are the initial runtime families. The showcase demonstrates
the installed families and will grow with the migrated flows. Unused chat,
billing and account components are intentionally outside this sports product.

## Data and assets

Original team crests retain their original colors. No brightness/invert filters
on raster artwork. Every missing or failed asset has a named initials fallback.
Portrait requests never establish statistical freshness. Zero is a value;
missing scores and probabilities remain absent. A past scheduled time does not
establish a finished result. Unverified pairings stay TBD.

## States and motion

Keep verified content while refreshing. Initial loading reserves the final
layout; error copy states a recovery action. Stale data has one dated notice
and disables new real picks. Every overlay has a title and focus restoration.
Keyboard switching is immediate. Pointer press feedback uses 150ms ease-out;
reduced motion disables transforms. No entry cascades or counting animations.

## Migration boundary

The React/TypeScript match desk owns the public entry point. Existing query
links resolve to their entity in the new interface. Tournament simulations and
shared desk transfers remain available through the labelled classic tools link;
those legacy query links retain their original view. Existing embeds, source
contracts and on-device pick storage remain compatible. No iframe wrapper.

## Known gaps

PandaScore Fixtures supplies schedules and results. Detailed current player
statistics and profile/photo completeness remain external data dependencies. A green build is not evidence that live data is available.
Light/dark, small-screen and keyboard checks are required per migrated flow.
